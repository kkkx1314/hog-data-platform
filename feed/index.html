口径说明

· 仔猪饲料 = 哺乳仔猪饲料 + 保育饲料；母猪饲料 = 后备母猪饲料 + 其他母猪饲料。
· 猪料（合计） = 仔猪饲料 + 母猪饲料 + 生长肥育猪饲料 + 其他猪饲料；分项不可相加。
· 季度产量 = 该季度 3 个月产量之和；季度环比 = 本季 ÷ 上季 − 1；季度同比 = 本季 ÷ 上年同季 − 1。只有 3 个月齐全的季度才计算。
· 四个口径互为校验：全部饲料 = 配合饲料 + 浓缩饲料 + 添加剂预混合饲料（2021-12 为已知历史修订差异）。
